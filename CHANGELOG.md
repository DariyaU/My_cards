# Changelog

All notable changes to the "My Cards" project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-01-XX

### Added
- **Core Functionality**:
  - Создание, редактирование и удаление наборов карточек (decks)
  - Добавление, редактирование и удаление карточек с полями "Вопрос" и "Ответ"
  - Копирование наборов и отдельных карточек
  - Локальное хранение данных через Hive (оффлайн-режим)
  
- **Режим обучения**:
  - Алгоритм интервального повторения SM-2
  - Оценка знаний по шкале от 1 до 5
  - Автоматический расчет следующего дня повторения
  - Перемешивание карточек для случайного порядка
  
- **Статистика**:
  - Подсчет общих карточек в наборе
  - Отслеживание выученных карточек (grade >= 3)
  - Отслеживание новых карточек
  - Статистика по каждому набору
  
- **Управление данными**:
  - Экспорт данных в JSON файл
  - Импорт данных из JSON файла
  - Печать карточек (текстовый формат, только вопросы)
  
- **Интерфейс**:
  - Адаптивный дизайн для мобильных устройств
  - Поддержка русского и английского языков интерфейса
  - Темная и светлая тема (design system)
  - Навигация между экранами (GoRouter)

### Changed
- Переименование проекта из "Flashcards" в "My Cards"
- Обновление структуры проекта согласно Clean Architecture
- Улучшение UI компонентов согласно Design System

### Fixed
- Исправлены ошибки сохранения данных при закрытии приложения
- Исправлена логика расчета интервалов повторения для новых карточек

### Technical
- Добавлены unit-тесты для алгоритма SM-2
- Добавлены integration-тесты для локального хранилища
- Настроен CI/CD pipeline для автотестов
- Добавлены адаптеры Hive для сериализации моделей
