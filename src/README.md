# Flashcards App - RU-EN Learning

Оффлайн Flutter приложение для изучения английских слов с помощью карточек.

## 📱 Возможности MVP

- ✅ Создание и управление наборами карточек (decks)
- ✅ Добавление, редактирование и удаление карточек
- ✅ Режим обучения с отметкой "Знаю" / "Не знаю"
- ✅ Статистика по каждому набору (всего, новых, выучено)
- ✅ Локальное хранение данных (Hive)
- ✅ Работа без интернета
- ✅ Русский и английский языки в интерфейсе

## 🏗️ Архитектура

Приложение построено на основе **Clean Architecture** с использованием паттерна **BLoC** для управления состоянием.

```
lib/
├── core/                    # Общие компоненты
│   ├── constants/           # Константы приложения
│   ├── errors/              # Обработка ошибок
│   ├── theme/               # Тема и стили
│   └── utils/               # Утилиты
├── data/                    # Слой данных
│   ├── local/               # Локальное хранилище
│   │   ├── models/          # Модели данных (Card, Deck)
│   │   ├── adapters/        # Адаптеры Hive
│   │   └── repositories/    # Репозитории
│   └── remote/              # (будущее расширение)
├── domain/                  # Бизнес-логика
│   ├── entities/            # Бизнес-объекты
│   ├── repositories/        # Интерфейсы репозиториев
│   └── usecases/            # Бизнес-правила
└── presentation/            # UI слой
    ├── blocks/              # BLoC компоненты
    ├── screens/             # Экраны приложения
    └── widgets/             # Переиспользуемые виджеты
```

## 🚀 Запуск приложения

### Требования
- Flutter SDK >= 3.0.0
- Android Studio / VS Code
- Эмулятор Android или физическое устройство

### Установка зависимостей
```bash
cd src
flutter pub get
```

### Генерация кода Hive
```bash
flutter pub run build_runner build --delete-conflicting-outputs
```

### Запуск
```bash
flutter run
```

Основные:

Для разработки:

- `build_runner` - кодогенерация
- `flutter_lints` - линтинг

## 📝 Структура данных

### Карточка (Card)
- `id` - уникальный идентификатор
- `question` - слово на английском
- `answer` - перевод на русский
- `createdAt` - дата создания
- `lastReviewedAt` - последнее повторение
- `repetitionCount` - количество повторений
- `easeFactor` - фактор легкости (SM-2)
- `intervalDays` - интервал до следующего повторения
- `isLearned` - статус изучения

### Набор (Deck)
- `id` - уникальный идентификатор
- `title` - название набора
- `description` - описание
- `createdAt` - дата создания
- `lastStudiedAt` - последнее изучение
- `cards` - список карточек
