# Software Requirements Specification (SRS)
## Проект: My Cards — Оффлайн приложение для изучения иностранных слов

| Метаданные | Значение |
|------------|----------|
| Версия | 1.0 |
| Статус | Черновик |
| Дата создания | 2024-01-XX |
| На основе | BRD v1.0 |

---

## 1. Введение

### 1.1. Назначение
Данный документ описывает функциональные и нефункциональные требования к приложению Flashcards. Документ предназначен для разработчиков, тестировщиков и заказчика.

### 1.2. Область применения
Приложение представляет собой мобильное Android-приложение для создания и изучения карточек со словами (русский-английский). Работает оффлайн, без сервера и аутентификации.

### 1.3. Определения и сокращения
См. документ `glossary.md`.

## 2. Функциональные требования (Functional Requirements)

### FR-01: Управление наборами карточек (Decks)
| Атрибут | Описание |
|---------|----------|
| Название | Создание, редактирование, удаление наборов карточек |
| Приоритет | Must Have |
| Описание | Пользователь может создавать новые наборы, давать им названия, редактировать название и удалять наборы вместе с содержимым. |
| Предусловия | Приложение запущено, пользователь находится на главном экране. |
| Постусловия | Список наборов обновлен. |
| Сценарий | 1. Нажать "Создать набор". 2. Ввести название. 3. Сохранить. |
| Альтернативы | Отмена создания. Удаление с подтверждением. |

### FR-02: Управление карточками (Cards)
| Атрибут | Описание |
|---------|----------|
| Название | Добавление, редактирование, удаление карточек в наборе |
| Приоритет | Must Have |
| Описание | Пользователь может добавлять карточки в набор (поля: Слово, Перевод), редактировать их и удалять. |
| Предусловия | Открыт конкретный набор карточек. |
| Постусловия | Список карточек обновлен. |
| Сценарий | 1. Нажать "Добавить карточку". 2. Ввести слово и перевод. 3. Сохранить. |
| Альтернативы | Валидация: оба поля обязательны. |

### FR-03: Режим изучения "Карточки"
| Атрибут | Описание |
|---------|----------|
| Название | Просмотр карточек с переворотом |
| Приоритет | Must Have |
| Описание | Пользователь видит слово, нажимает для показа перевода, затем отмечает знание. |
| Предусловия | В наборе есть хотя бы одна карточка. Запущен режим обучения. |
| Постусловия | Статус карточки обновлен (Знаю/Не знаю). |
| Сценарий | 1. Показать слово. 2. Нажать "Показать ответ". 3. Нажать "Знаю" или "Не знаю". |

### FR-04: Фильтрация для повторения
| Атрибут | Описание |
|---------|----------|
| Название | Повторение только карточек "Не знаю" |
| Приоритет | Must Have |
| Описание | При запуске режима обучения пользователь может выбрать повторение только тех карточек, которые помечены как "Не знаю". |
| Предусловия | Есть карточки со статусом "Не знаю". |
| Постусловия | В сессию включены только отфильтрованные карточки. |

### FR-05: Статистика по набору
| Атрибут | Описание |
|---------|----------|
| Название | Отображение статистики изучения |
| Приоритет | Should Have |
| Описание | На экране набора отображается: всего карточек, выучено ("Знаю"), не выучено ("Не знаю"), процент прогресса. |
| Предусловия | В наборе есть карточки. |
| Постусловия | Пользователь видит актуальную статистику. |

### FR-06: Экспорт/Импорт данных (JSON)
| Атрибут | Описание |
|---------|----------|
| Название | Резервное копирование данных |
| Приоритет | Could Have |
| Описание | Пользователь может экспортировать все наборы в JSON-файл и импортировать обратно. |
| Предусловия | Есть созданные наборы (для экспорта). Есть файл JSON (для импорта). |
| Постусловия | Данные сохранены в файл / загружены из файла. |

### FR-07: Локализация интерфейса
| Атрибут | Описание |
|---------|----------|
| Название | Поддержка RU и EN языков интерфейса |
| Приоритет | Must Have |
| Описание | Пользователь может выбрать язык интерфейса (Русский или Английский) в настройках. |
| Предусловия | Приложение запущено. |
| Постусловия | Все тексты интерфейса отображаются на выбранном языке. |

## 3. Нефункциональные требования (Non-Functional Requirements)

### NFR-01: Производительность
| Атрибут | Описание |
|---------|----------|
| Название | Быстродействие приложения |
| Описание | Время запуска приложения < 2 сек. Время отклика UI < 100 мс. Работа со списком до 1000 карточек без лагов. |

### NFR-02: Надежность и сохранность данных
| Атрибут | Описание |
|---------|----------|
| Название | Локальное хранение данных |
| Описание | Данные сохраняются после закрытия приложения и перезагрузки устройства. Использование SQLite или Hive. |

### NFR-03: Совместимость
| Атрибут | Описание |
|---------|----------|
| Название | Поддержка версий Android |
| Описание | Минимальная версия Android: 8.0 (API level 26). |

### NFR-04: Доступность (Accessibility)
| Атрибут | Описание |
|---------|----------|
| Название | Базовая доступность |
| Описание | Поддержка скринридеров, достаточный контраст цветов, возможность навигации с клавиатуры (для планшетов). |

### NFR-05: Масштабируемость данных
| Атрибут | Описание |
|---------|----------|
| Название | Объем данных |
| Описание | Приложение должно корректно работать при наличии до 50 наборов и до 1000 карточек в одном наборе. |

### NFR-06: Безопасность
| Атрибут | Описание |
|---------|----------|
| Название | Локальная безопасность |
| Описание | Так как нет сервера, требования сводятся к отсутствию утечек данных через логирование. Не хранить чувствительные данные. |

### NFR-07: Интернационализация (i18n)
| Атрибут | Описание |
|---------|----------|
| Название | Архитектура локализации |
| Описание | Все строки интерфейса вынесены в ресурсные файлы (arb). Хардкод строк запрещен. |

## 4. Бизнес-правила (Business Rules)

| ID | Правило | Описание |
|----|---------|----------|
| BR-01 | Обязательность полей | Поля "Слово" и "Перевод" в карточке являются обязательными для заполнения. |
| BR-02 | Уникальность названия набора | Названия наборов могут повторяться (не является уникальным ключом). |
| BR-03 | Статус карточки | Карточка может иметь только один статус: "Новая", "Знаю", "Не знаю". По умолчанию "Новая". |
| BR-04 | Удаление набора | При удалении набора все карточки внутри него удаляются безвозвратно (если не сделан экспорт). |
