# Матрица трассировки требований (Traceability Matrix)

## Назначение
Данный документ обеспечивает прослеживаемость требований от бизнес-целей до тест-кейсов и реализации кода. Заполняется по ходу проекта.

## Легенда
- **BR** — Бизнес-требование (из BRD)
- **FR** — Функциональное требование (из SRS)
- **NFR** — Нефункциональное требование (из SRS)
- **US** — User Story
- **TC** — Тест-кейс
- **PR** — Pull Request / Коммит

## Инструкции по обновлению
1. При создании новой User Story — добавить строку в таблицу.
2. При написании тест-кейса — указать его ID в колонке "Связанные тест-кейсы".
3. При завершении PR — указать номер PR в колонке "PR / Коммит" и обновить статус.
4. При изменении требований — обновить соответствующие строки и добавить запись в таблицу обновлений.
