# Глоссарий терминов (Glossary)

## Основные термины

| Термин (RU) | Термин (EN) | Определение |
|-------------|-------------|-------------|
| **Набор карточек** | **Deck** | Коллекция карточек, объединенных одной темой (например, "Еда", "Глаголы", "Путешествия"). Пользователь создает наборы для группировки слов. |
| **Карточка** | **Card** | Единица обучения. Содержит два основных поля: "Термин" (слово на одном языке) и "Определение" (перевод на другой язык). |
| **Термин** | **Term** | Слово или фраза на исходном языке (например, русское слово в режиме RU→EN). Отображается на лицевой стороне карточки. |
| **Определение** | **Definition** | Перевод термина на целевой язык (например, английское слово). Отображается на оборотной стороне карточки после переворота. |
| **Режим изучения** | **Study Mode** | Интерактивный сеанс работы с карточками, в котором пользователь просматривает карточки по одной и отмечает свой уровень знания. |
| **Знаю** | **Know** | Статус карточки, который пользователь присваивает, если вспомнил перевод без затруднений. Карточки со статусом "Знаю" исключаются из повторения. |
| **Не знаю** | **Don't Know** | Статус карточки, который пользователь присваивает, если не вспомнил перевод. Такие карточки подлежат повторению в следующих сессиях. |
| **Новая карточка** | **New Card** | Карточка, которая еще ни разу не проходила режим изучения. Статус по умолчанию при создании. |
| **Интервальное повторение** | **Spaced Repetition** | Методика запоминания, при которой карточки показываются через увеличивающиеся промежутки времени. В MVP реализовано упрощенно: повтор только карточек "Не знаю". |
| **Прогресс** | **Progress** | Процентное соотношение выученных карточек к общему количеству в наборе. |
| **Экспорт** | **Export** | Процесс сохранения всех данных приложения (наборы и карточки) в внешний файл (JSON) для резервного копирования. |
| **Импорт** | **Import** | Процесс загрузки данных из внешнего JSON-файла в приложение. |
| **Локализация** | **Localization (l10n)** | Адаптация интерфейса приложения под конкретный язык (Русский или Английский). |
| **Интернационализация** | **Internationalization (i18n)** | Архитектурная подготовка приложения к поддержке нескольких языков (вынос строк в ресурсные файлы). |
| **MVP** | **MVP (Minimum Viable Product)** | Минимально жизнеспособный продукт. Версия приложения с базовым функционалом: создание карточек, режим изучения, статистика. Без сервера, без картинок, без аудио. |
| **Оффлайн** | **Offline** | Режим работы приложения без подключения к интернету. Все данные хранятся локально на устройстве. |
| **Стейкхолдер** | **Stakeholder** | Заинтересованное лицо (в данном проекте: Заказчик, Разработчик, Тестировщик). |
| **User Story** | **User Story** | Пользовательская история. Описание функции с точки зрения пользователя: "Как <роль>, я хочу <действие>, чтобы <ценность>". |
| **Acceptance Criteria** | **Acceptance Criteria** | Критерии приёмки. Список условий, которые должны быть выполнены для того, чтобы User Story считалась реализованной. |
| **Wireframe** | **Wireframe** | Черновой макет экрана, показывающий расположение элементов интерфейса без детального дизайна. |

## Статусы карточки (Card Statuses)

| Статус | Описание | Когда присваивается |
|--------|----------|---------------------|
| `NEW` (Новая) | Карточка создана, но еще не изучалась | При создании карточки |
| `KNOW` (Знаю) | Пользователь уверенно знает перевод | После нажатия кнопки "Знаю" в режиме изучения |
| `DON'T_KNOW` (Не знаю) | Пользователь затруднился с ответом | После нажатия кнопки "Не знаю" в режиме изучения |

## Технические термины

| Термин | Определение |
|--------|-------------|
| **Hive** | Легковесная NoSQL база данных для Flutter, используемая для локального хранения данных. |
| **SQLite** | Реляционная база данных, альтернатива Hive для хранения структурированных данных. |
| **ARL (Arb)** | Формат файлов локализации в Flutter (Application Resource Bundle). |
| **Widget** | Базовый строительный блок интерфейса во Flutter. |
| **State Management** | Управление состоянием приложения (в MVP может использоваться `setState` или `Provider`). |
| **CI/CD** | Continuous Integration / Continuous Delivery. Автоматизация сборки и тестирования (в данном проекте — GitHub Actions). |
