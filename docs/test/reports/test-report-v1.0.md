## 4. Выявленные замечания и риски

### 🔴 Критические (S1)
*   *Нет.* Логика сохранения и основная бизнес-логика не содержат явных ошибок, ведущих к крашу при стандартном использовании.

### 🟡 Средние (S2/S3)
1.  **Обработка длинных текстов:** В коде используется простое отображение текста. На маленьких экранах длинный вопрос/ответ может выходить за границы.
    *   *Рекомендация:* Проверить wrapping текста на устройстве с малым экраном.
2.  **Подтверждение удаления:** В текущей реализации Flutter UI модалка подтверждения может требовать уточнения текстов (локализация RU/EN).
    *   *Рекомендация:* Убедиться, что строки вынесены в ресурсы (arb файлы), если планируется мультиязычность интерфейса.
3.  **Экспорт/Импорт:** Файловая система мобильных ОС (Android/iOS) требует запроса разрешений или использования специфичных пакетов (`file_picker`, `path_provider`) для реальной записи файла на диск. В текущем коде логика сериализации есть, но интеграция с файловой системой телефона может потребовать доработки под конкретную ОС.
    *   *Рекомендация:* Протестировать кнопку "Экспорт" на реальном Android. Если файл не скачивается — добавить `permission_handler`.

### 🟢 Улучшения (Enhancements)
*   Добавить анимацию переворота карточки (Flip animation) для лучшего UX.
*   Добавить визуальную индикацию прогресса в режиме обучения (например, `LinearProgressIndicator`).

## 5. Инструкция для ручной верификации (Manual QA)

Поскольку данный отчет составлен на основе анализа кода, необходимо выполнить следующие шаги на реальном устройстве или эмуляторе:

1.  **Сборка:**
    ```bash
    cd src
    flutter pub get
    flutter build apk --debug  # Для Android
    ```
2.  **Запуск:** Установить APK на устройство.
3.  **Сценарий 1 (Happy Path):**
    *   Создать набор "English Words".
    *   Добавить 3 карточки.
    *   Закрыть приложение (свайпом).
    *   Открыть приложение -> Проверить, что данные сохранились.
4.  **Сценарий 2 (Обучение):**
    *   Зайти в набор -> "Начать повторение".
    *   Нажать "Не знаю" на первой карточке.
    *   Пройти до конца.
    *   Проверить, что карточка осталась в списке "На повторение".
5.  **Сценарий 3 (Экспорт):**
    *   Зайти в Настройки -> Экспорт.
    *   Проверить наличие файла `.json` в папке загрузок устройства.
