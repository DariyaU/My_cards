# План тестирования (Test Plan)
**Проект:** Flashcards (My Cards)  
**Версия:** 1.0  
**Дата:** 2024-05-20

## 1. Объект тестирования
Мобильное приложение Flutter для Android (оффлайн) для изучения иностранных слов.

## 2. Объем тестирования (Scope)
### Включено:
- Управление наборами карточек (создание, редактирование, удаление, копирование)
- Управление карточками (добавление, редактирование, удаление)
- Режим обучения (показ карточек, отметка "Знаю"/"Не знаю")
- Алгоритм интервального повторения
- Сохранение данных в локальном хранилище
- UI/UX всех экранов

### Исключено:
- Сетевое взаимодействие
- Авторизация/Регистрация
- Импорт/Экспорт (в бэклоге)

## 3. Роли и ответственность
| Роль | Ответственность |
| :--- | :--- |
| QA Engineer | Создание тест-кейсов, ручное тестирование, отчеты |
| Developer | Unit/Widget тесты, фикс багов |
| Product Owner | Acceptance testing, приемка функционала |

## 4. Окружение
- **Dev:** Эмулятор Android 13 (Pixel 6)
- **Stage:** Физическое устройство (Samsung Galaxy A52)
- **Prod:** Устройства пользователей (Android 10+)

## 5. Расписание
| Этап | Длительность | Ответственный |
| :--- | :--- | :--- |
| Подготовка тестов | 1 день | QA |
| Тестирование функционала | 2 дня | QA |
| Фикс багов | 1-2 дня | Dev |
| Regression | 0.5 дня | QA |
| Acceptance | 0.5 дня | PO |

## 6. Риски
- Потеря данных при краше приложения → Тестирование восстановления
- Некорректная работа алгоритма → Детальное тестирование SM-2

## 7. Критерии начала тестирования
- Готов билд приложения (.apk)
- Пройдены Unit-тесты
- Готова тестовая документация

## 8. Критерии завершения тестирования
- Все критические тест-кейсы пройдены
- Нет багов S1/S2
- Подписан акт приемки
