# TC-001: Создание нового набора карточек

| Параметр | Значение |
| :--- | :--- |
| **ID** | TC-001 |
| **Заголовок** | Создание нового набора карточек |
| **Связанное требование** | FR-001, US-001 |
| **Приоритет** | Critical |
| **Тип** | Позитивный |
| **Предусловия** | Приложение запущено, экран "Мои наборы" открыт |

## Шаги воспроизведения
1. Нажать кнопку "+ Новый набор"
2. Ввести название набора в поле ввода (например, "English Words")
3. Нажать кнопку "Сохранить"

## Ожидаемый результат
- Набор создан и отображается в списке
- Название набора соответствует введенному
- Счетчик карточек равен 0
- Данные сохранены в локальном хранилище

## Фактический результат
_Заполняется при тестировании_
