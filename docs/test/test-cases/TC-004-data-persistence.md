# TC-004: Сохранение данных после перезапуска приложения

| Параметр | Значение |
| :--- | :--- |
| **ID** | TC-004 |
| **Заголовок** | Проверка сохранения данных после перезапуска приложения |
| **Связанное требование** | NFR-003, US-006 |
| **Приоритет** | Critical |
| **Тип** | Позитивный |
| **Предусловия** | Создан набор с минимум 2 карточками, проведена сессия обучения |

## Шаги воспроизведения
1. Создать набор карточек с названием "Test Deck"
2. Добавить 2 карточки в набор
3. Провести сессию обучения, отметить 1 карточку как "Знаю"
4. Полностью закрыть приложение (убить процесс)
5. Запустить приложение заново
6. Открыть набор "Test Deck"

## Ожидаемый результат
- Набор "Test Deck" отображается в списке
- В наборе ровно 2 карточки
- Карточки содержат введенные ранее вопрос и ответ
- Статус изученности карточек сохранен (1 "Знаю", 1 "Не знаю")
- Данные загружены из локального хранилища, не потеряны
