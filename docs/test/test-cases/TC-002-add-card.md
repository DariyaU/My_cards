# TC-002: Добавление новой карточки в набор

| Параметр | Значение |
| :--- | :--- |
| **ID** | TC-002 |
| **Заголовок** | Добавление новой карточки в набор |
| **Связанное требование** | FR-003, US-003 |
| **Приоритет** | Critical |
| **Тип** | Позитивный |
| **Предусловия** | Существует хотя бы один набор карточек |

## Шаги воспроизведения
1. Открыть существующий набор карточек
2. Нажать кнопку "+ Новая карточка"
3. Ввести текст вопроса (например, "Cat")
4. Ввести текст ответа (например, "Кот")
5. Нажать кнопку "Сохранить"

## Ожидаемый результат
- Карточка создана и отображается в списке карточек набора
- Вопрос и ответ соответствуют введенным данным
- Счетчик карточек в наборе увеличился на 1
- Данные сохранены в локальном хранилище

_Заполняется при тестировании_
