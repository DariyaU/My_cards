# TC-003: Проведение сессии повторения (алгоритм SM-2)

| Параметр | Значение |
| :--- | :--- |
| **ID** | TC-003 |
| **Заголовок** | Проведение сессии повторения карточек |
| **Связанное требование** | FR-005, US-005 |
| **Приоритет** | Critical |
| **Тип** | Позитивный |
| **Предусловия** | В наборе есть минимум 3 карточки |

## Шаги воспроизведения
1. Открыть набор с карточками
2. Нажать кнопку "Начать повторение"
3. Просмотреть вопрос на карточке
4. Нажать "Показать ответ"
5. Если знаете ответ: нажать "Знаю"
6. Если не знаете: нажать "Не знаю"
7. Повторить для всех карточек в сессии

## Ожидаемый результат
- Карточки показываются по одной
- Ответ скрыт до нажатия кнопки "Показать ответ"
- Кнопка "Знаю" отмечает карточку как изученную
- Кнопка "Не знаю" оставляет карточку на повторение
- После завершения показывается статистика сессии
- Статусы карточек сохраняются в локальном хранилище
