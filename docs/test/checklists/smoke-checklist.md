# Smoke Test Checklist (Дымовое тестирование)
**Проект:** My Cards  
**Версия:** 1.0  
**Цель:** Быстрая проверка критического функционала перед глубоким тестированием

## Критерии прохождения
Все пункты должны быть отмечены как **PASS**. Любой **FAIL** блокирует дальнейшее тестирование.

| # | Проверка | Ожидаемый результат | Статус |
| :--- | :--- | :--- | :--- |
| 1 | Запуск приложения | Приложение запускается без крашей за < 3 сек | [ ] Pass / [ ] Fail |
| 2 | Главный экран | Отображается список наборов (или пустое состояние) | [ ] Pass / [ ] Fail |
| 3 | Создание набора | Кнопка "+ Новый набор" работает, форма открывается | [ ] Pass / [ ] Fail |
| 4 | Сохранение набора | Набор сохраняется и отображается в списке | [ ] Pass / [ ] Fail |
| 5 | Открытие набора | Набор открывается, виден список карточек | [ ] Pass / [ ] Fail |
| 6 | Добавление карточки | Карточка создается с вопросом и ответом | [ ] Pass / [ ] Fail |
| 7 | Режим обучения | Кнопка "Начать повторение" работает, карточки показываются | [ ] Pass / [ ] Fail |
| 8 | Отметка "Знаю/Не знаю" | Кнопки работают, статусы сохраняются | [ ] Pass / [ ] Fail |
| 9 | Перезапуск приложения | Данные сохраняются после закрытия и открытия | [ ] Pass / [ ] Fail |
