# UI Flows (Пользовательские сценарии)

## 1. Главная страница (Список наборов)

```
+----------------------------------+
|  Flashcards              [Настройки] |
+----------------------------------+
|                                  |
|  [+ Новый набор]                 |
|                                  |
|  📚 Английский - Еда (15 карт)   |
|     > Изучить                    |
|     > Редактировать              |
|     > Удалить                    |
|                                  |
|  📚 Английский - Путешествия (8) |
|     > Изучить                    |
|     > Редактировать              |
|     > Удалить                    |
|                                  |
|  📚 Глаголы неправильные (22)    |
|     > Изучить                    |
|     > Редактировать              |
|     > Удалить                    |
|                                  |
+----------------------------------+
|  [Главная]  [Статистика] [Профиль]|
+----------------------------------+
```

**Сценарий:**
1. Пользователь открывает приложение → Отображается список всех наборов
2. Пользователь нажимает "[+ Новый набор]" → Открывается модальное окно создания
3. Пользователь вводит название → Нажимает "Создать" → Набор появляется в списке
4. Пользователь нажимает "Изучить" на наборе → Переход к режиму обучения
5. Пользователь нажимает "Редактировать" → Переход к экрану редактирования набора

---

## 2. Экран редактирования набора

```
+----------------------------------+
|  < Назад    Английский - Еда   [+] |
+----------------------------------+
|                                  |
|  Карточки в наборе: 15           |
|                                  |
|  +-----------------------------+ |
|  | Q: Apple                    | |
|  | A: Яблоко                   | |
|  | [✏️] [🗑️] [📄]             | |
|  +-----------------------------+ |
|                                  |
|  +-----------------------------+ |
|  | Q: Bread                    | |
|  | A: Хлеб                     | |
|  | [✏️] [🗑️] [📄]             | |
|  +-----------------------------+ |
|                                  |
|  ... (список карточек)           |
|                                  |
+----------------------------------+
|  [Начать повторение]             |
+----------------------------------+
```

**Сценарий добавления карточки:**
1. Пользователь нажимает "[+]" → Открывается форма
2. Вводит "Вопрос" (английское слово)
3. Вводит "Ответ" (перевод на русский)
4. Нажимает "Сохранить" → Карточка добавляется в список

**Сценарий редактирования карточки:**
1. Пользователь нажимает "[✏️]" на карточке
2. Открывается форма с текущими данными
3. Пользователь меняет текст → "Сохранить"

**Сценарий удаления карточки:**
1. Пользователь нажимает "[🗑️]"
2. Появляется подтверждение: "Удалить карточку?"
3. Пользователь подтверждает → Карточка удалена

## 3. Режим обучения (Карточки)

```
+----------------------------------+
|  < Выход    Прогресс: 5/15       |
+----------------------------------+
|                                  |
|        ┌─────────────────┐       |
|        │                 │       |
|        │    APPLE        │       |
|        │                 │       |
|        │  (нажми чтобы   │       |
|        │   показать)     │       |
|        │                 │       |
|        └─────────────────┘       |
|                                  |
|        [Показать ответ]          |
|                                  |
+----------------------------------+
|  [❌ Не знаю]     [✅ Знаю]      |
+----------------------------------+
```

**После нажатия "Показать ответ":**
```
+----------------------------------+
|  < Выход    Прогресс: 5/15       |
+----------------------------------+
|                                  |
|        ┌─────────────────┐       |
|        │    APPLE        │       |
|        │    -----        │       |
|        │    ЯБЛОКО       │       |
|        └─────────────────┘       |
|                                  |
+----------------------------------+
|  [❌ Не знаю]     [✅ Знаю]      |
+----------------------------------+
```

**Сценарий:**
1. Показывается только вопрос
2. Пользователь пытается вспомнить перевод
3. Нажимает "Показать ответ" → Появляется перевод
4. Пользователь оценивает знание:
   - "Знаю" → Карточка помечается как изученная, следующая
   - "Не знаю" → Карточка остаётся в пуле для повторения
5. После всех карточек → Экран результатов

## 6. Навигация

**Основная навигация (Bottom Navigation Bar):**
- 🏠 Главная (список наборов)
- 📊 Статистика (общая прогресс)
- ⚙️ Настройки (экспорт/импорт, сброс данных)

**Глобальные действия:**
- Кнопка "Назад" (<) во всех вложенных экранах
- Модальные окна для форм (создание/редактирование)

---

## Интерактивность

| Элемент | Действие | Результат |
|---------|----------|-----------|
| [+ Новый набор] | Tap | Модальное окно ввода названия |
| Название набора | Tap | Переход к экрану набора |
| Изучить | Tap | Запуск режима обучения |
| Редактировать | Tap | Переход к редактору набора |
| Удалить набор | Tap | Подтверждение → Удаление набора и всех карточек |
| [+] (карточка) | Tap | Форма добавления карточки |
| ✏️ | Tap | Форма редактирования карточки |
| 🗑️ | Tap | Подтверждение → Удаление карточки |
| 📄 | Tap | Копирование карточки в тот же набор |
| Карточка (вопрос) | Tap | Переворот, показ ответа |
| ✅ Знаю | Tap | Пометка "выучено", переход к следующей |
| ❌ Не знаю | Tap | Оставить в пуле повторения, переход к следующей |
| Экспорт | Tap | Сохранение JSON файла на устройство |
| Импорт | Tap | Выбор JSON файла → Добавление наборов |
