# Release Notes - My Cards v1.0.0

**Дата релиза:** Январь 2024  
**Версия:** 1.0.0 (MVP)  
**Тип релиза:** Major Release (Первая публичная версия)

---

## 🎯 Цель релиза
Первый стабильный релиз приложения "My Cards" для изучения иностранных языков с помощью карточек. Приложение работает полностью оффлайн, все данные хранятся локально на устройстве пользователя.

---

## ✨ Новые возможности

### Управление наборами карточек
- **Создание наборов**: Пользователи могут создавать неограниченное количество наборов карточек
- **Редактирование**: Изменение названия набора в любое время
- **Копирование**: Быстрое дублирование наборов с суффиксом "(копия)"
- **Удаление**: Удаление наборов с подтверждением операции

### Управление карточками
- **Добавление карточек**: Создание карточек с полями "Вопрос" (термин) и "Ответ" (перевод/определение)
- **Редактирование**: Изменение содержимого карточек
- **Копирование**: Дублирование карточек внутри набора
- **Удаление**: Удаление карточек с подтверждением

### Режим обучения с интервальным повторением
- **Алгоритм SM-2**: Научно обоснованный алгоритм для оптимального запоминания
- **Оценка знаний**: 5-балльная шкала (от 1 - "не знаю" до 5 - "идеально")
- **Автоматическое планирование**: Расчет следующего дня повторения на основе оценки
- **Перемешивание**: Случайный порядок карточек в сессии
- **Статистика сессии**: Подсчет изученных карточек в реальном времени

### Статистика и прогресс
- **Общая статистика набора**: Количество всех карточек
- **Выученные карточки**: Карточки с оценкой >= 3
- **Новые карточки**: Карточки, которые еще не изучались
- **Прогресс изучения**: Визуальное отображение прогресса по каждому набору

### Управление данными
- **Экспорт в JSON**: Сохранение всех данных в файл для резервного копирования
- **Импорт из JSON**: Восстановление данных из ранее сохраненного файла
- **Печать карточек**: Генерация печатной версии набора (только вопросы)

### Интерфейс и UX
- **Адаптивный дизайн**: Оптимизация для мобильных устройств Android
- **Двуязычный интерфейс**: Русский и английский языки
- **Design System**: Единая система цветов, типографики и компонентов
- **Навигация**: Плавные переходы между экранами

## 🔧 Технические улучшения

### Архитектура
- **Clean Architecture**: Разделение на слои (data, domain, presentation)
- **BLoC Pattern**: Управление состоянием приложения
- **Hive Database**: Быстрое локальное хранилище NoSQL
- **GoRouter**: Декларативная навигация

### Тестирование
- **Unit-тесты**: Покрытие бизнес-логики (алгоритм SM-2)
- **Integration-тесты**: Тестирование работы с базой данных
- **Test Coverage**: Целевое покрытие >80% критического кода

### Производительность
- **Мгновенная загрузка**: Все данные локально, нет сетевых запросов
- **Оптимизация памяти**: Эффективное управление большими списками карточек
- **Быстрый поиск**: O(1) доступ к карточкам по ID

## 📱 Системные требования

- **Платформа**: Android 5.0 (API level 21) и выше
- **Память**: Минимум 50 MB свободного места
- **Разрешение экрана**: Поддержка всех разрешений от 320x480
- **Интернет**: Не требуется (полностью оффлайн)

## 📝 Известные ограничения

### Текущая версия (MVP)
- Только текстовый формат карточек (без изображений и аудио)
- Один пользователь (нет аутентификации и синхронизации)
- Только русский и английский языки интерфейса
- Нет облачного резервного копирования (только локальный экспорт/импорт)

### Планы на будущие версии
