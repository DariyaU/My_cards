## Описание (User Story)

**Как** пользователь,  
**Я хочу** видеть статистику по каждому набору (сколько выучено, сколько осталось),  
**Чтобы** отслеживать свой прогресс и мотивировать себя на дальнейшее изучение.

---

## Критерии приёмки (Acceptance Criteria)

### AC-001: Отображение общей статистики
**Given** Пользователь открыл набор  
**When** Пользователь просматривает экран набора  
**Then** Отображается: всего карточек, выучено ("Знаю"), не выучено ("Не знаю" + "Новые")

### AC-002: Процент прогресса
**Given** В наборе есть карточки с разными статусами  
**When** Пользователь просматривает статистику  
**Then** Отображается процент выученных карточек (Знаю / Всего * 100)

### AC-003: Визуализация прогресса (опционально)
**Given** Пользователь просматривает статистику  
**When** Реализован визуальный компонент (progress bar / pie chart)  
**Then** Прогресс отображается графически

### AC-004: Обновление статистики в реальном времени
**Given** Пользователь прошел сессию изучения  
**When** Пользователь вернулся к экрану набора  
**Then** Статистика обновлена с учетом новых статусов карточек

## Примечания

- Формула прогресса: `(knowCount / totalCount * 100).round()`

- "Не выучено" = "Новые" + "Не знаю".
