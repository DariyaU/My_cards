## Описание (User Story)

**Как** пользователь,  
**Я хочу** создавать, редактировать и удалять наборы карточек,  
**Чтобы** группировать слова по темам (например, "Еда", "Глаголы", "Путешествия") и удобно ими управлять.

---

## Критерии приёмки (Acceptance Criteria)

### AC-001: Создание нового набора
**Given** Пользователь находится на главном экране  
**When** Пользователь нажимает кнопку "Создать набор" и вводит название  
**Then** Новый набор отображается в списке наборов с названием и счетчиком карточек (0)

### AC-002: Редактирование названия набора
**Given** Пользователь находится на главном экране и видит список наборов  
**When** Пользователь выбирает опцию "Редактировать" у существующего набора и меняет название  
**Then** Название набора обновляется в списке

### AC-003: Удаление набора
**Given** Пользователь находится на главном экране  
**When** Пользователь выбирает опцию "Удалить" у набора  
**Then** Появляется диалог подтверждения "Удалить набор [Название] и все его карточки?"  
**When** Пользователь подтверждает удаление  
**Then** Набор и все его карточки удаляются из списка

### AC-004: Отображение количества карточек
**Given** В наборе есть карточки  
**When** Пользователь просматривает список наборов  
**Then** Рядом с названием набора отображается количество карточек в нём

### AC-005: Пустой список наборов
**Given** Пользователь запустил приложение впервые  
**When** Пользователь находится на главном экране  
**Then** Отображается сообщение "Нет наборов. Создайте первый набор!" и кнопка "Создать набор"
