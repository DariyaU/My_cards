## Описание (User Story)

**Как** пользователь,  
**Я хочу** повторять только те карточки, которые я отметил как "Не знаю",  
**Чтобы** сосредоточиться на сложных словах и эффективнее их запомнить.

---

## Критерии приёмки (Acceptance Criteria)

### AC-001: Фильтрация карточек "Не знаю"
**Given** В наборе есть карточки со статусом "Не знаю"  
**When** Пользователь выбирает опцию "Повторить сложные" (или аналог)  
**Then** В сессию включаются ТОЛЬКО карточки со статусом "Не знаю"

### AC-002: Пустой результат фильтрации
**Given** В наборе нет карточек со статусом "Не знаю" (все выучены)  
**When** Пользователь выбирает опцию "Повторить сложные"  
**Then** Появляется сообщение "Все карточки выучены! Отличная работа!" и кнопка "Вернуться"

### AC-003: Изменение статуса при повторении
**Given** Пользователь проходит сессию с карточками "Не знаю"  
**When** Пользователь нажимает "Знаю" на карточке  
**Then** Статус карточки меняется на "Знаю", она исключается из будущих повторений

### AC-004: Подсчет результатов сессии
**Given** Пользователь завершил сессию повторения  
**When** Показан экран завершения  
**Then** Отображается количество повторенных карточек и сколько из них отмечено как "Знаю"
