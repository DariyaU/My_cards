## Описание (User Story)

**Как** пользователь,  
**Я хочу** экспортировать все свои наборы в файл и импортировать их обратно,  
**Чтобы** иметь резервную копию данных и возможность переноса на другое устройство.

---

## Критерии приёмки (Acceptance Criteria)

### AC-001: Экспорт всех данных
**Given** Пользователь имеет созданные наборы с карточками  
**When** Пользователь выбирает "Экспорт данных" в настройках  
**Then** Создается JSON-файл со всеми наборами и карточками, файл сохраняется в Downloads

### AC-002: Формат JSON файла
**Given** Пользователь выполнил экспорт  
**When** Пользователь открывает сохраненный файл  
**Then** Файл содержит валидный JSON со структурой: `{ "decks": [{ "id", "title", "cards": [...] }] }`

### AC-003: Импорт данных из файла
**Given** Пользователь имеет JSON-файл с экспортированными данными  
**When** Пользователь выбирает "Импорт данных" и указывает файл  
**Then** Данные из файла загружаются в приложение, наборы отображаются в списке

### AC-004: Обработка ошибок импорта
**Given** Пользователь выбрал невалидный JSON-файл  
**When** Пользователь пытается выполнить импорт  
**Then** Появляется сообщение об ошибке "Неверный формат файла", данные не загружаются

### AC-005: Слияние данных при импорте
**Given** В приложении уже есть наборы  
**When** Пользователь импортирует данные из файла  
**Then** Импортированные наборы добавляются к существующим (без дублирования по ID)

## Примечания

- Для работы с файлами на Android потребуется разрешение `READ_EXTERNAL_STORAGE` / `WRITE_EXTERNAL_STORAGE` или использование `Storage Access Framework`.
- Рекомендуемая структура JSON:
```json
{
  "version": "1.0",
  "exportedAt": "2024-01-XXT00:00:00Z",
  "decks": [
    {
      "id": "deck-uuid",
      "title": "Название",
      "createdAt": "2024-01-XXT00:00:00Z",
      "cards": [
        {
          "id": "card-uuid",
          "term": "Слово",
          "definition": "Перевод",
          "status": "NEW|KNOW|DON'T_KNOW",
          "createdAt": "2024-01-XXT00:00:00Z"
        }
      ]
    }
  ]
}
```
