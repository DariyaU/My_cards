## Описание (User Story)

**Как** пользователь,  
**Я хочу** редактировать и удалять существующие карточки в наборе,  
**Чтобы** исправлять ошибки в переводе и удалять ненужные слова.

---

## Критерии приёмки (Acceptance Criteria)

### AC-001: Редактирование карточки
**Given** Пользователь открыл набор и видит список карточек  
**When** Пользователь нажимает "Редактировать" на карточке, меняет текст в полях и нажимает "Сохранить"  
**Then** Изменения сохраняются, карточка обновляется в списке

### AC-002: Валидация при редактировании
**Given** Пользователь редактирует карточку  
**When** Пользователь очищает одно из полей и нажимает "Сохранить"  
**Then** Появляется ошибка "Оба поля обязательны", изменения не сохраняются

### AC-003: Удаление карточки
**Given** Пользователь открыл набор  
**When** Пользователь нажимает "Удалить" на карточке  
**Then** Появляется диалог подтверждения "Удалить эту карточку?"  
**When** Пользователь подтверждает  
**Then** Карточка удаляется из списка

### AC-004: Отмена удаления
**Given** Пользователь нажал "Удалить" на карточке  
**When** Появился диалог подтверждения  
**When** Пользователь нажимает "Отмена"  
**Then** Диалог закрывается, карточка остается в списке
