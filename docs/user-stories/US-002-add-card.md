## Описание (User Story)

**Как** пользователь,  
**Я хочу** добавлять новые карточки в выбранный набор,  
**Чтобы** пополнять свой словарь словами для изучения.

---

## Критерии приёмки (Acceptance Criteria)

### AC-001: Добавление карточки с валидацией
**Given** Пользователь открыл существующий набор  
**When** Пользователь нажимает кнопку "Добавить карточку", вводит "Слово" и "Перевод", нажимает "Сохранить"  
**Then** Карточка добавляется в список карточек набора со статусом "Новая"

### AC-002: Валидация обязательных полей
**Given** Пользователь открыл форму добавления карточки  
**When** Пользователь оставляет поле "Слово" или "Перевод" пустым и нажимает "Сохранить"  
**Then** Появляется сообщение об ошибке "Оба поля обязательны для заполнения", карточка не сохраняется

### AC-003: Отображение списка карточек
**Given** В наборе есть одна или более карточек  
**When** Пользователь открывает набор  
**Then** Отображается список карточек с полями "Слово" и "Перевод" (перевод скрыт до нажатия)

### AC-004: Сохранение данных
**Given** Пользователь добавил карточку в набор  
**When** Пользователь закрывает и перезапускает приложение  
**Then** Добавленная карточка отображается в наборе (данные сохранены локально)
