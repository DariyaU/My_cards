## Описание (User Story)

**Как** пользователь,  
**Я хочу** просматривать карточки по одной с возможностью переворота,  
**Чтобы** проверять свои знания и запоминать перевод слов.

---

## Критерии приёмки (Acceptance Criteria)

### AC-001: Запуск режима изучения
**Given** Пользователь открыл набор с карточками  
**When** Пользователь нажимает кнопку "Начать изучение"  
**Then** Открывается экран режима изучения, показывается первая карточка (только термин)

### AC-002: Переворот карточки (показать ответ)
**Given** Пользователь видит карточку с термином (лицевая сторона)  
**When** Пользователь нажимает на карточку или кнопку "Показать ответ"  
**Then** Карточка переворачивается, отображается перевод (обратная сторона)

### AC-003: Оценка знания (Знаю)
**Given** Пользователь видит перевернутую карточку (термин + перевод)  
**When** Пользователь нажимает кнопку "Знаю"  
**Then** Статус карточки меняется на "Знаю", показывается следующая карточка

### AC-004: Оценка знания (Не знаю)
**Given** Пользователь видит перевернутую карточку (термин + перевод)  
**When** Пользователь нажимает кнопку "Не знаю"  
**Then** Статус карточки меняется на "Не знаю", показывается следующая карточка

### AC-005: Завершение сессии
**Given** Пользователь просмотрел все карточки в сессии  
**When** Показана последняя карточка и пользователь оценил её  
**Then** Появляется экран завершения с сообщением "Изучено X карточек" и кнопкой "Вернуться к набору"

### AC-006: Навигация между карточками
**Given** Пользователь находится в режиме изучения  
**When** Пользователь может переходить к следующей/предыдущей карточке (если реализовано)  
**Then** Карточки листаются без изменения статуса (опционально для MVP)
