## Описание (User Story)

**Как** пользователь,  
**Я хочу** переключать язык интерфейса приложения между русским и английским,  
**Чтобы** использовать приложение на удобном для меня языке.

---

## Критерии приёмки (Acceptance Criteria)

### AC-001: Выбор языка в настройках
**Given** Пользователь находится на экране настроек  
**When** Пользователь выбирает язык из списка (RU / EN)  
**Then** Все тексты интерфейса немедленно обновляются на выбранный язык

### AC-002: Сохранение выбора языка
**Given** Пользователь выбрал язык (например, EN)  
**When** Пользователь закрывает и перезапускает приложение  
**Then** Приложение запускается с ранее выбранным языком (EN)

### AC-003: Язык по умолчанию
**Given** Пользователь запустил приложение впервые  
**When** Приложение запускается  
**Then** Язык определяется по системному языку устройства (если поддерживается) или устанавливается RU по умолчанию

### AC-004: Полная локализация
**Given** Пользователь переключил язык  
**When** Пользователь просматривает все экраны приложения  
**Then** Все текстовые элементы (кнопки, заголовки, сообщения, ошибки) отображаются на выбранном языке

## Примечания

- Структура ARB-файлов:
```json
// app_ru.arb
{
  "appTitle": "Карточки",
  "createDeck": "Создать набор",
  "addCard": "Добавить карточку",
  "know": "Знаю",
  "dontKnow": "Не знаю",
  ...
}

// app_en.arb
{
  "appTitle": "Flashcards",
  "createDeck": "Create Deck",
  "addCard": "Add Card",
  "know": "Know",
  "dontKnow": "Don't Know",
  ...
}
```
- Использовать `Intl.message` или `AppLocalizations.of(context)!` для доступа к строкам.
- При изменении языка требуется перезапуск приложения или hot-reload контекста.
