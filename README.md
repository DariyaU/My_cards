# Мои Карточки (Lite)

Приложение для создания, редактирования и повторения карточек с вопросами и ответами. Все данные сохраняются локально в браузере через localStorage.

## Функциональность

- Создание, редактирование, удаление и копирование наборов карточек
- Создание, редактирование, удаление и копирование отдельных карточек
- Режим повторения для заучивания карточек (только карточки "не изучено")
- Отметка карточек как "знаю"/"не знаю" во время повторения
- Статистика по каждому набору (всего карточек, изучено, не изучено, новых)
- Возможность печати карточек (только вопросы)
- Экспорт и импорт данных для синхронизации между браузерами
- Сохранение данных в localStorage (данные сохраняются после перезагрузки страницы)
- Адаптивный интерфейс

## Техническая информация

- HTML + CSS + JavaScript (vanilla)
- Данные хранятся в localStorage
- Не требуется регистрация, сервер или авторизация
- Поддержка современных браузеров (Chrome, Firefox, Edge)

## Структура данных

```json
{
  "sets": [
    {
      "id": "уникальный_идентификатор",
      "title": "Название набора",
      "cards": [
        {
          "id": "уникальный_идентификатор_карточки",
          "question": "Вопрос",
          "answer": "Ответ",
          "status": "new|known|unknown"  // статус карточки: новая, изучена, не изучена
        }
      ]
    }
  ],
  "syncToken": null  // для синхронизации между браузерами (опционально)
}
```

1. Склонируйте репозиторий
2. Откройте файл `index.html` в браузере
