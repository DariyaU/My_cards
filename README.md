# My Cards

**My Cards** — это мобильное приложение для изучения иностранных слов с помощью карточек и интервального повторения (алгоритм SM-2). Приложение работает полностью оффлайн, все данные хранятся локально на вашем устройстве.

![Flutter](https://img.shields.io/badge/flutter-3.x-blue.svg)

## 🚀 Особенности

- **Полностью оффлайн**: Не требует интернета, все данные хранятся локально на устройстве.
- **Интервальное повторение (SM-2)**: Умный алгоритм планирования повторений для эффективного запоминания.
- **Управление наборами**: Создавайте, редактируйте, удаляйте и копируйте наборы карточек.
- **Гибкое управление карточками**: Добавляйте вопросы и ответы, редактируйте, удаляйте или дублируйте карточки.
- **Статистика прогресса**: Отслеживайте количество выученных, новых и сложных карточек в каждом наборе.
- **Экспорт/Импорт**: Сохраняйте резервные копии данных в JSON и восстанавливайте их.
- **Печать карточек**: Возможность печати списков вопросов для обучения без экрана.
- **Простой интерфейс**: Интуитивно понятный дизайн, адаптированный для мобильных устройств.

## 📥 Установка

### Вариант 1: Установка APK
1. Скачайте файл `MyCards-v1.0.0.apk` из раздела [Releases](https://github.com/DariyaU/My_cards/releases).
2. Передайте файл на ваше Android-устройство.
3. Разрешите установку приложений из неизвестных источников в настройках телефона.
4. Запустите APK-файл и следуйте инструкциям установщика.

### Вариант 2: Сборка из исходного кода
Если вы хотите собрать приложение самостоятельно:

**Требования:**
- Flutter SDK 3.x или выше
- Android Studio / Android SDK
- Git

**Шаги:**
```bash
# 1. Клонируйте репозиторий
git clone https://github.com/DariyaU/My_cards.git
cd My_cards/src

# 2. Установите зависимости
flutter pub get

# 3. Запустите приложение (на подключенном эмуляторе или устройстве)
flutter run

# 4. Или соберите релизный APK
flutter build apk --release
```
Собранный APK будет находиться по пути: `build/app/outputs/flutter-apk/release/app-release.apk`

## 📖 Как использовать

1. **Создание набора**: На главном экране нажмите «+ Новый набор», введите название (например, "Английские слова").
2. **Добавление карточек**: Откройте набор, нажмите «+ Новая карточка», введите слово на английском (вопрос) и перевод (ответ).
3. **Обучение**: Нажмите «Начать повторение». Приложение покажет слово, затем ответ. Отметьте «Знаю» или «Не знаю». Алгоритм сам решит, когда показать карточку снова.
4. **Просмотр статистики**: На экране набора видно, сколько карточек уже выучено, а сколько требует повторения.

## 🏗️ Архитектура и Технологии

- **Язык**: Dart
- **Фреймворк**: Flutter
- **Архитектура**: Clean Architecture + BLoC (Business Logic Component)
- **Локальное хранилище**: Hive (быстрая NoSQL база данных)
- **Навигация**: GoRouter
- **Алгоритм**: SM-2 (SuperMemo-2) для интервального повторения

Структура проекта соответствует принципам разделения ответственности:
- `lib/data/`: Модели данных, локальное хранилище (Hive), адаптеры.
- `lib/domain/`: Бизнес-логика, сущности, репозитории (интерфейсы).
- `lib/presentation/`: UI экраны, виджеты, BLoC классы.
- `lib/core/`: Утилиты, константы, алгоритмы (SM-2).
